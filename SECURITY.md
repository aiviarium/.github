# Security

This page applies to every repository in the organisation that has no
`SECURITY.md` of its own. A repository's own page says where that project is
meant to run and what it treats as a vulnerability.

## Supported versions

Fixes go into the latest release of each project. Projects at 0.x don't
maintain older releases.

## Reporting a vulnerability

Please don't open a public issue. Use **Report a vulnerability** under the
Security tab of the repository concerned, which opens a private report to the
maintainers.

Say what you found, how to reproduce it and what an attacker gains. You'll get
an answer within a week. Once a fix is released, the report is published with
credit to you, unless you'd rather not be named.
